# ManyMotions /video-generation

Источник навыка: [ManyMotions cursor-plugins](https://github.com/manymotions/cursor-plugins).
Сначала проверь реально доступные MCP-инструменты: разные версии сервера имеют
разные имена. Не вызывай отсутствующие инструменты из старого описания.

AI-клип: краткий промпт (герой, действие, окружение, камера, свет, стиль), затем
доступные модели/параметры/стоимость. `media_forge_generate` и старый
`generate_media_forge` расходуют кредиты. Старый `prepare_media_forge_project`
только готовит проект, если он доступен. Перед платным вызовом требуется явное
согласие на конкретную стоимость; установка навыка таким согласием не является.
При запрете расходов не запускай генерацию даже для проверки баланса.

Бесплатный маршрут при наличии редактора: `video_editor_create_project` →
`video_editor_set_context` → импорт предоставленных медиа через
`video_editor_request_upload` + PUT → `video_editor_add_reference` →
`video_editor_add_clip`. Сохраняй project_id и полученные URL/asset_id в выпуске.
`video_editor_instruct` может запускать платный AI; не используй его при нулевом
бюджете. Стоимость/доступность экспорта проверяй до запуска. Ошибка billing или
недостаток кредитов — основание использовать локальную сборку, а не покупать тариф.

Для «Столбиков» длительность, карточки и проверку ведёт video-producer. Новую тему
сначала проверь одной пробой из трёх карточек. Повторяй только по просьбе или при
заметном дефекте. Один AI-клип не
заменяет полный длинный ролик. При бесплатной локальной сборке прямо укажи, что
рисунки/анимация созданы локально, а ManyMotions использован как проект/редактор.
Не обещай бесплатную AI-генерацию без подтверждённой возможности сервиса.

После запуска оплаченного задания проверяй статус до завершения и верни готовое
медиа. Не подменяй результат ссылкой на пустой проект. При account_required нужен
вход пользователя; при billing_required сообщи ограничение один раз.
