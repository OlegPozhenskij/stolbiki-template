# Одна проба перед полным выпуском

Пользователь экономит лимит: по умолчанию один цикл, без обязательных трёх версий.
Применять к новой теме/оформлению. Для обычной замены текста сохраняй готовый вид.

1. Выбери три разных героя: сложный силуэт, длинное название, большое число.
2. Создай только эти карточки, собери check.jpg и просмотри его один раз.
   Примени quality-filter: факты отдельно от субъективной оценки оформления.
   Проверь читаемость, единицы, целый силуэт, наложения и характеры. Короткий
   анимационный пилот нужен только для нового или проблемного движения.
3. Исправь конкретные замечания, кратко запиши решение в review.json/md и создай
   остальных героев. Не запускай новые варианты ради формального числа проверок.

Дополнительный цикл — по явной просьбе или если обнаружен заметный дефект.
Техническую проверку длительности/звука выполняет штатный рендер. Успешные тесты
не повторяй без изменения кода или новой причины; документация не требует тестов.
Храни brief/status/review, используй кэш. В следующем чате читай состояние выпуска,
а не всю историю. Не выдавай условный масштаб и художественную мимику за факты.
