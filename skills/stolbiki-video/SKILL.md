# Сборка «Столбиков»

Работай в репозитории OlegPozhenskij/stolbiki-template. Сначала прочитай его
AGENTS.md и brief/status нужного выпуска. Новый интерфейс описан в
docs/usage.md, контракты в docs/contracts.md. Не читай весь движок для нового ролика.
Если бриф выбирает профиль сравнения, прочитай docs/video-process.md: там общие
правила размера, центрирования, рисунка, факта и одной проверки этого шаблона.

Постоянное: четыре столбика, появление снизу, счётчик, движение героя, камера,
приглушение старых карточек и финальный вопрос. Тема, изображения, оформление,
окружение, музыка и длительность задаются выпуском. Не ограничивай все темы
животными, карандашом или конкретной площадкой. Не меняй поведение без запроса.

Файлы episodes/<id>/: brief.json, content.json, sources.json, assets.json,
status.json. Никогда не затирай другой выпуск или src/generated вручную.
Создание: `npm run episode -- new <id> --title Тема --seconds 60`.
Заполни карточки, источники и соответствие id готовым сценам/изображениям.
Схема слоёв: background, foreground с прозрачностью, composite и bounds.
Готовые сцены ищи в assets/catalog.json, нужный модуль читай отдельно.
Карандашные ограничения см. [pencil.md](references/pencil.md) только для pencil;
новая сцена регистрируется в каталоге отдельным модулем.

Команды:
- `npm run episode -- validate <id>`: данные, длительность, наличие источников.
- `npm run episode -- preview <id>`: изображения, сборка и out/<id>/check.jpg.
- При точечной правке: `preview <id> --cards <card-id>`; без фильтра видны все карточки.
- Открой лист: текст читается, герой целиком, бейдж и вопрос ничего не закрывают.
- Исправь конкретную проблему, затем `npm run episode -- render <id>`.
- Проверь out/<id>/verification.json и готовое видео; отдай MP4 и обложку.

Кэш обновляется по содержимому: не удаляй tmp, public/generated или out между
правками. Не устанавливай зависимости заново, если среда исправна. Ошибки
выводи кратко; полный лог читай только при сбое. Состояние rendered означает
техническую сборку, а не доказанную научную достоверность или визуальное одобрение.
Для фактов, текста и идей выбирай отдельный навык только при необходимости.
Для новой темы/оформления достаточно одной пробы из трёх карточек: создание →
просмотр с quality-filter → нужные правки → остальные герои. Дополнительные циклы
только по просьбе пользователя или при заметном дефекте. Порядок хранится в
video-producer/references/visual-cycle.md. При точечной правке используй готовые
решения и кэш; не повторяй уже пройденные проверки без причины.
Если пользователь требует только stolbiki-video, соблюдай это ограничение.
