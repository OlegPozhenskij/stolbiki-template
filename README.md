# Столбики

Remotion-шаблон сравнительных видео: общий движок карточек, отдельные выпуски,
сменные оформления и окружения, библиотека слоёв, музыка и кэш рендера.

Начните с [инструкции и готовых запросов](docs/usage.md).
Форматы данных: [контракты](docs/contracts.md).
Решения по перестройке: [архитектура](docs/architecture.md).

```sh
npm run episode -- preview animal-longevity
npm run episode -- render animal-longevity
```

Нужны установленные зависимости; подготовка описана в инструкции.
Для нового чата достаточно вызвать `video-producer`, задать тему, длительность
и пожелания к оформлению. Для точечной правки укажите id выпуска и карточки.
