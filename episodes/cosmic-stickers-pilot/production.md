# Проба реальных фотостикеров

24 секунды: МКС → Бенну → 67P → Луна → Сатурн → Солнце. Шесть разных категорий
с возрастающими размерами. 67P выбрана вместо Галлея ради различимого рельефа.
Текущий объём — только шесть карточек; полный выпуск ждёт просмотра пользователем.

Сценарий подготовил Codex по полным video-producer и video-script-writer,
без DeepSeek/VVoice. Ядро: в космосе можно рассмотреть реальные миры и сравнить
несопоставимые на первый взгляд размеры. Вопрос: насколько огромен космос?
Структура — шесть зрительных открытий; у каждого одно короткое утверждение.
Озвучка не добавлялась, остаются музыка и звуки появления прежнего шаблона.

Факты проверены быстрым режимом полного quality-filter: сон в закреплённых
на стене мешках — CSA/ESA; образцы Бенну — NASA OSIRIS-REx FAQ; форма «уточки» —
ESA Comet Horizon; лунные моря из лавы — NASA Moon Facts; ледяные частицы колец —
NASA Cassini FAQ; время света от Солнца — NASA Earth Facts. Размеры повторно взяты
из сохранённых проверенных записей cosmic-size-300, новых чисел не придумывали.

Фото и кредиты перечислены в media.json; это фотографии/фотомозаики, не AI-рисунки.
Солнце — УФ-наблюдение в назначенном цвете, пометка есть на экране. Кольца не входят
в числовой размер Сатурна. Главное тело масштабируется по physicalSizeKm;
окружение схематично, его условный масштаб обозначен на экране.

Визуальный цикл один: просмотр контрольного листа → устранение квадратов
JPEG-фона в маске стикеров → рендер. Новые самостоятельные варианты не создавались.

Воспроизведение: node --use-system-ca scripts/sticker-download.mjs (если фото
отсутствуют), node scripts/sticker-workshop.mjs, npm run episode -- preview
cosmic-stickers-pilot, затем npm run episode -- render cosmic-stickers-pilot.
Оригиналы фото отслеживаются в Git; SVG-маски и обводки создаёт workshop.
