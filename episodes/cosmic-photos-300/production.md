# Крупные фотографии

Правка принятого cosmic-stickers-300: те же 75 изображений, факты, порядок, музыка, фон, анимация, шестиугольник и нижний блок. Убраны маска и белая обводка стикеров, все дополнительные объекты и уменьшение прежних карточек. Каждый главный объект постоянно занимает большую область карточки без искажения пропорций. Старый выпуск сохранён.

Повторная подготовка: node scripts/plain-photos.mjs && python scripts/render-stickers.py cosmic-photos-300. Затем штатные preview/render. Никаких новых сценариев, изображений, поиска источников или платных вызовов.
