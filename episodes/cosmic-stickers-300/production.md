# Полный выпуск фотостикеров

Пользователь принял оформление шестикарточной пробы и поручил собрать пять минут.
75 карточек по четыре секунды, восемь планет и67 других космических объектов.
Порядок размеров возрастающий. Вступление и финальный вопрос внутри300секунд.

Сохранены три широких столбика, правильный шестиугольник и один короткий факт.
Последние правки: все дополнительные тела/аппараты тоже стикеры; метаданные под
объектом удалены; нижняя панель увеличена со164до188px; усилилось мягкое движение
самих объектов без деформации; фон слегка различается по оттенку и свечению.

64 объекта/измерения переиспользованы из проверенной основы cosmic-size-300,
11 замен подобраны для разнообразия:2011MD, FalconHeavy, Дидим, Диморф, Таутатис,
Географ, Седна, Квавар, Плеяды,47Тукана,M13. Для шести объектов сохранены принятые
подписи пробы. Текст подготовлен самим Codex по video-producer/video-script-writer,
без DeepSeek/VVoice. Новые числа и факты сверены с первичными источниками;
неопределённости размеров и определения измерений сохранены в sources.json.

По разрешению пользователя для нерешённых дисков/поверхностей допускаются
научные визуализации. Их тип и авторство находятся в media.json и CREDITS.md.
Реконструкции, УФ/ИК-снимки и условные цвета не называются фотографиями поверхности.
Солнце — SDO/AIA; Альдебаран и Сириус представлены моделями; для пульсара используется
типовая иллюстрация класса. Числовые пропорции относятся к главным телам;
декоративный контекст и лучи/кольца в отдельных стикерах имеют собственный масштаб.

Музыка оригинальная, синтезирована локально: мягкие аккорды, стеклянные переборы,
тихий басовый пульс, воздушные звуки появления. Скрипт cosmic-music.py,
music=cosmic. Платная генерация, сторонние музыкальные сэмплы и DeepSeek не нужны.

Повторная сборка готовых входов:
```
npm run episode -- preview cosmic-stickers-300 --cards earth,saturn,jupiter,andromeda
npm run episode -- render cosmic-stickers-300
```
После замены фото/кадрирования сначала:
```
node --use-system-ca scripts/photo-download.mjs
python scripts/photo-shapes.py
node scripts/photo-workshop.mjs
python scripts/render-stickers.py
```
Не запускать повторный поиск картинок или подготовку сценария ради рендера.
Внеплановые загрузки и исследовательские черновики сохранены в tmp, не в рабочих
входах. Исходные изображения, выбранные маски, факты и решения сохраняются в Git.

Один цикл визуальной доработки по принятому оформлению: обзор75 стикеров,
выбранные окна выпуска и обложка. Исправления масок и встроенных подписей — часть
этого цикла. Прежние оформления просмотрены; 18 технических тестов прошли.

Экспорт завершён 16 ноября 2026: 15 фрагментов, 300.000 секунд видео и музыки,
9000 кадров, 1920×1080 / 30 fps, H.264 + AAC. Размер MP4 — 223 691 834 байта.
Штатная проверка длительности, кадров, разрешения и звука пройдена;
результат — out/cosmic-stickers-300/video.mp4, обложка — thumb.png,
технический отчёт — verification.json в той же папке. Полный повторный рендер
или дополнительный творческий цикл не запускался.
