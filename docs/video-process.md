# Процесс сравнительного видео

Сначала рассчитай число карточек: (длительность минус отдельные заставка/финал)
÷ время карточки. Для пяти минут по четыре секунды — 75 карточек; вступление
и финальный вопрос при необходимости накладываются внутри этих 300 секунд.

Сценарий строится вокруг интересного детям вопроса. На карточке только название,
один конкретный короткий факт и понятная величина в верхнем блоке. Дополнительные
характеристики вроде «любопытный сосед» не добавлять. Проверенные факты и числа
сохраняются по id; определения измеряемого размера нельзя незаметно смешивать.

В этом шаблоне:
- Нижнюю светлую панель сохранять. Название и один факт увеличить и центрировать
  по горизонтали; держать одинаковые уровни строк и безопасные поля.
- Верхняя область преимущественно отдана рисунку. Над ним шестиугольник с крупным
  центрированным числом и единицей. Бейдж не должен забирать отдельную большую полосу.
- Рисунки карандашные, крупные, с точным силуэтом. Круги не растягивать и не мять.
  Лица заметные, эмоции разнообразные. У каждого героя своё окружение.
- Космические украшения, пролёт, моргание, поворот и короткая реакция оживляют
  появление; не закрывают текст и не искажают реальную форму объекта.
- При сравнении размеров использовать физические значения и единый линейный
  масштаб соседей. Смена увеличения обозначается; логарифмическую или минимальную
  условную величину не выдавать за реальную пропорцию. Для колец, хвостов,
  горизонта событий, звёздного диска и галактики хранить явное определение размера.
  Текущий выбранный порядок — от меньшего к большему: новый герой крупный,
  предыдущие уменьшаются. Краткий крупный план входа явно отделять от сравнения.

Сначала одна проба из трёх разных объектов и один просмотр с quality-filter.
Исправить найденные проблемы, затем создать остальные карточки по выбранным
правилам. Не делать три версии и повторные проверки без просьбы/заметного дефекта.
Штатный рендер один раз проверяет длительность, число кадров и наличие звука.
Данные, решения и исходники хранить в Git, кэш использовать повторно.

Это настройки данного шаблона, а не запрет другим выпускам выбирать другую палитру,
мир, предметы или формат числового блока по новому запросу пользователя.
