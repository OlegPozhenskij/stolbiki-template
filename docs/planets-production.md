# Планеты: как продолжать

Цель: 180 секунд, 1920×1080, 30 fps; восемь планет по возрастанию
экваториального диаметра. Рисунки условные, не в масштабе. На карточку 21 секунда:
основной факт и две сменные подписи по 7 секунд. Заставка и финал по 6 секунд.

Пилоты planets-pilot-1, planets-pilot-2, planets-pilot-3 — отдельные пробы по
три карточки (Земля, Сатурн, Юпитер), по 20 секунд. review.json фиксирует просмотр
и реальные изменения. После третьего просмотра создаётся planets-journal-180.
Данные выпуска, исходники иллюстраций и дизайн хранятся в Git; результаты out/
создаются командами. Старые выпуски не заменяются.

Новая настройка пользователя: по умолчанию одна проба и одна проверка. Три
пилота выше — уже выполненная история этого выпуска; повторять их не нужно.

ManyMotions: project_id vp_10a4f2995b004400bed9. Используются бесплатные операции
редактора, готовые рисунки и локальное видео. Платная AI-генерация отключена.
Не путать установленный навык с бесплатным доступом к Kling/Veo.

Команды из D:/stolbiki:
```powershell
npm run episode -- preview planets-journal-180 --cards saturn
npm run episode -- render planets-journal-180
```
Открой out/planets-journal-180/check.jpg до рендера. Выход: video.mp4, thumb.png,
verification.json. Повторная сборка использует кэш, не удаляй его при правках.

В новом чате достаточно написать:
«$video-producer, проект D:/stolbiki. Новый выпуск <id>, тема <тема>, 3 минуты.
Поведение карточек сохранить. Дизайн <оставить/описать>. Без платных сервисов.
Для новой визуальной темы достаточно одной пробы из трёх карточек и quality-filter».

Для правки: «Продолжи planets-journal-180. Измени только <что>. Используй готовые
карточки и кэш». Не нужно перечислять все навыки и пересылать историю.
