# Как делать следующие ролики

Новый ролик удобно начинать в новом чате этого проекта. Правки продолжайте в
чате его выпуска. История чата не заменяет файлы: решения сохраняются в episodes/.

## Что написать Codex

Новый выпуск по шаблону пяти минут:
> Используй video-producer и профиль docs/video-process.md. Новая тема: «[тема]».
> Создай отдельный выпуск [id]: 75 карточек по 4 секунды, от меньшего к большему.
> Сохрани оформление cosmic-pencil-hex, один факт внизу и реальный масштаб.
> Одна проба из трёх карточек и один просмотр, затем итоговый MP4. Без платных сервисов.

Продолжить текущую работу без повторного исследования:
> Продолжи cosmic-size-300 по brief.json и status.json. Используй сохранённые
> источники, рисунки и кэш. Новые проверки только для изменённых частей.

Полный ролик:
> Используй video-producer. Сделай «Самые быстрые животные» на 60 секунд для
> детей 8–15 лет. Создай выпуск animal-speed. Дизайн pencil-album, мир native.
> Возьми готовые изображения, недостающие добавь. Проверь факты, просмотри
> предпросмотр и выдай MP4 с обложкой. Детали выбери самостоятельно.

Есть тема, но нет подачи:
> Используй video-producer. Предложи три подачи для видео о планетах.
> Формат карточек сохраняем. Пока нужны только идеи.

Новое оформление:
> В выпуске animal-longevity поменяй дизайн на space-atlas. Тексты, числа и
> поведение карточек сохрани. Проверь кадры и собери MP4.

Другое окружение и способ изображения:
> Создай копию выпуска под новым id. Выбери world cosmos и media vector.
> Дизайн pencil-album оставь. Покажи предпросмотр.

Точечная правка:
> В animal-longevity поправь только подпись карточки cat. Число и смысл факта
> сохрани. Пересобери видео с использованием кэша.

Только сборка:
> Используй только stolbiki-video. Файлы выпуска уже готовы. Проверь и
> собери animal-longevity; не придумывай заново тему и сценарий.

Не требуется перечислять все навыки. video-producer выбирает нужный этап.
После установки навыки доступны со следующего сообщения; если список не обновился,
перезапустите Codex. Локальные навыки не переносятся автоматически в веб-ChatGPT.

## Однократная подготовка компьютера

Нужны Node 20+, Python 3.11+ и установленный Chrome/Chromium.

```sh
npm ci
python -m pip install -r requirements.txt
npm run setup
npm run skills:install
```

На Linux вместо python обычно python3. При необходимости задайте STOLBIKI_PYTHON
и CHROME полными путями. ffmpeg/ffprobe берутся из установленного Remotion.
Python-браузер использует установленный Chrome, отдельно скачивать Playwright
браузеры не требуется. При исправной среде эти команды не повторяются каждый раз.
`skills:install` сохраняет предыдущие версии в tmp/skill-backups и копирует семь
навыков в личную папку Codex. Оригинальные пользовательские навыки не пропадают.

## Создание и сборка

```sh
npm run episode -- list
npm run episode -- new my-video --title "Моя тема" --seconds 60
```

Заполните `episodes/my-video/content.json`, `sources.json`, `assets.json`.
Черновые источники pending не проходят проверку. Десять карточек по 5 с,
заставка 5 с и финал 5 с дают ровно минуту. Другую длительность задавайте в brief;
для нестандартного количества есть `--cards 8`. Шаг должен быть целым числом кадров.

```sh
npm run episode -- validate my-video
npm run episode -- preview my-video
npm run episode -- render my-video
```

Между preview и render откройте `out/my-video/check.jpg`. Проверьте переносы,
размер текста, силуэты, слои и отсутствие перекрытий. После ручных правок
повторите preview затронутого выпуска. Для точечной правки используйте
`npm run episode -- preview my-video --cards cat,axolotl`; без --cards
контрольный лист включает текст каждой карточки. Команда render сама не оценивает красоту.

Готовые файлы: `out/my-video/video.mp4`, `thumb.png`, `verification.json`.
rendered в status означает технически собранный файл, не редакционное одобрение.
Источники проверяет автор/агент, программа проверяет их заполнение и сроки.

## Готовые примеры

- animal-longevity: сохранённый минутный выпуск с источниками.
- cosmic-size-300: пять минут, 75 объектов по четыре секунды, включая восемь планет;
  от меньшего к большему, реальный линейный масштаб соседей. Одна проба — cosmic-size-pilot.
  Настройки этого шаблона и порядок работы: [video-process.md](video-process.md).
- planets-journal-180: три минуты, восемь планет, сменные проверенные подписи.
- planets-pilot-1/2/3: три последовательные 20-секундные пробы по три карточки;
  review.json сохраняет наблюдения, правки и выбранный вариант.
- design-lab-pencil: четыре тестовые карточки с планетами, карандашный альбом.
- design-lab-atlas: те же карточки, космический атлас и звёздный фон.

Числа в design-lab демонстрационные и не являются научными фактами.
kind=demo допустим только для явно обозначенной демонстрации оформления.

Для новой темы или нового визуального языка video-producer делает одну пробу из
трёх карточек с просмотром и quality-filter, затем остальные изображения.
Дополнительные циклы — по просьбе или при заметном дефекте; при обычной правке
готового выпуска цикл не повторяется.
Запрос, настройки трёх минут и продолжение планет: [planets-production.md](planets-production.md).
ManyMotions /video-generation подключён к маршруту продюсера; бесплатный монтаж
готовых медиа и локальная сборка не означают бесплатную AI-генерацию Kling/Veo.

## Что повторяется, а что берётся из кэша

Изображение зависит от сцены, общих помощников, мира и способа обработки.
Смена текста или дизайна не рисует героя заново. Внешние изображения учитываются
по содержимому файла. Изменение общего помощника пересобирает зависимые сцены.

Видео разбито по 600 кадров. Ключ фрагмента учитывает видимые карточки,
заставку/финальный вопрос, изображения, код, оформление и шрифты. При смене времени
или порядка безопасно пересчитываются зависимые фрагменты. Обложка и музыка имеют
свои ключи. Изменение только музыки не требует перерисовки кадров. Полный повтор
без изменений возвращает проверенный готовый MP4.

Не удаляйте out, public/generated и tmp между правками. При прерванном рендере
повторите команду: завершённые фрагменты используются повторно. Две сборки
одновременно в одной папке не запускаются; для параллельных выпусков нужны
отдельные рабочие копии.

## GitHub

До слияния PR эта версия находится в ветке `codex/reusable-episodes`.
Для новой рабочей копии переключитесь на неё: `git switch codex/reusable-episodes`.
После слияния используйте обычную main.

Проверки разработки: `npm test`, `npm run typecheck` после prepare и
`npm run skills:check` (на Linux при необходимости python3 scripts/check-skills.py).

В Git хранятся код, выпуски, источники, сцены, настройки и навыки. Видео,
готовые PNG/JPG, кэши и установленные пакеты исключены. Дополнительные внешние
фото храните у себя в public/ или отдельном хранилище; передайте их следующему
компьютеру отдельно. Исходные SVG-сцены из этого проекта восстанавливаются сборкой.
Рабочую версию движка можно закрепить коммитом или тегом для воспроизводимости.
