# Выпуски, оформление и навыки

Принятый пользователем подход, 2026-11-15.

Цель: выпуск создаётся из небольших файлов данных. Поведение четырёх карточек,
счётчика, камеры и финального вопроса остаётся общим. Оформление, окружение,
изображения и текст выбираются независимо. Готовый минутный выпуск сохраняется.

Рассмотрены: копия шаблона для каждого ролика (накапливает исправления), большой
универсальный компонент с условиями (трудно расширять), общий движок с выпусками
и подключаемым оформлением (выбранный подход).

Границы реализации: один репозиторий, локальная сборка Windows/Linux, два реально
работающих оформления, библиотека отдельных SVG-сцен, общий контракт слоёв,
проверки данных и воспроизводимый рендер с кэшем. Новая графика не требует менять
движок. Отдельный сайт, облачный сервис и новые зависимости для интерфейса не нужны.

Навык `video-producer` выбирает этап по задаче и сохранённому состоянию выпуска.
Шесть специализированных навыков остаются самостоятельными. Их короткие входные
файлы ссылаются на тематические справочники; справочники не загружаются все сразу.
Глобальные оригиналы сохраняются в локальной резервной копии. Управляемые версии
навыков хранятся в `skills/`, команда установки синхронизирует их с Codex.

Проверка: тесты времени/валидации/кэша, TypeScript, контрольные кадры обоих
оформлений, настоящий MP4 со звуком, повторный запуск без повторного рендера,
проверка поведения навыка независимым читателем.

Порядок: сохранить выпуск → выделить контракт/время/анимацию → оформления и миры
→ команды/кэш/проверки → навыки/руководство → рендер/повторная проверка → PR.
